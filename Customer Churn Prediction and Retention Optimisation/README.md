# Customer Churn Prediction and Retention Optimisation

## Information

Used telecommunications customer data to predict customer churn and analyse how service usage, billing, customer characteristics, equipment, and retention-related features are associated with churn behaviour.

Cleaned and prepared the data in R, conducted exploratory analysis, and trained Logistic Regression, K-Nearest Neighbours, and Random Forest models. Model performance was compared to identify an appropriate model for predicting customer churn.

Evaluated predictive performance using Accuracy, Precision, Recall, F1 Score, and ROC-AUC. The project also identified high-risk customers, optimised a customer retention discount strategy based on expected profit, and used Monte Carlo simulation to assess churn and profit risk under uncertainty.

## Tools

R, dplyr, tidyr, ggplot2, caret, randomForest, pROC, Logistic Regression, K-Nearest Neighbours, Random Forest, Monte Carlo Simulation
